# LGGL

LGU+ 기가라이트 회선에서 싸제 공유기를 사용하기 위한 패키지입니다. 반기가 지원 허브를 연결해도 500Mbps가 나오지 않거나, 일정 시간이 지나 “인증”이 풀리면서 100Mbps로 제한되는 문제를 해결합니다.

## 요구사항

- OpenWrt 25.12가 설치된 공유기 (아래 지원 아키텍처 참고)
- 4선 기가라이트(하프기가)를 지원하는 허브  
  보통 반기가 지원 제품으로 광고됩니다.

## 사용 방법

원선 → 반기가 지원 허브 → OpenWrt 공유기의 WAN 포트 순서로 연결합니다.

가능하면 WAN MAC 주소를 기존 통신사 공유기의 WAN MAC과 동일하게 설정하는 것을 권장합니다.

아래 설치 과정을 거친 뒤 LuCI의 **Services → LGGL**에서 응답할 장치를 선택하고 **Apply**를 누릅니다. 일반적으로는 원선에 연결된 WAN 장치 하나만 선택하면 됩니다.

설치 직후에는 응답할 장치가 지정되어 있지 않으므로 직접 선택해야 합니다. 보통 WAN을 지정하면 됩니다.

## 설치

설치 스크립트는 공유기의 CPU 아키텍처에 맞는 패키지를 자동으로 선택합니다.
지원 아키텍처: `aarch64_cortex-a53`, `aarch64_cortex-a72`, `aarch64_generic`, `arm_cortex-a7_neon-vfpv4`, `arm_cortex-a15_neon-vfpv4`, `mips_24kc`, `mipsel_24kc`, `x86_64`.
OpenWrt 24.10 이하의 `opkg` 환경은 지원하지 않습니다.

공유기에 root 계정으로 SSH 접속한 뒤 다음 명령을 실행합니다.

```sh
wget -qO- https://github.com/hyoseupjang/LGGL/releases/latest/download/install.sh | sh
```

최신 릴리스의 `lggl`과 `luci-app-lggl` 패키지를 내려받아 설치하고, 서비스 자동 시작도 함께 설정합니다.

APK 파일을 직접 받으려면 [Releases](https://github.com/hyoseupjang/LGGL/releases) 페이지를 이용하세요.

설치 후 LuCI를 새로고침한 다음 **Services → LGGL**에서 설정을 마무리합니다.

## 테스트 현황

### 확인된 항목

- WAN MAC을 통신사 공유기의 MAC으로 변경한 상태에서 약 3일간 속도 유지 확인
- 다산 상단 장비에서 요청 수신 및 응답 패킷 전송 확인

### 미확인 항목

- 사제 공유기의 원래 WAN MAC을 그대로 사용한 경우의 동작  
  기존 인증이 오래 유지되어 아직 테스트하지 못했습니다.
- 상단 장비가 유비쿼스인 회선에서의 동작  
  가능성은 있어 보이지만 확인되지는 않았습니다.
- 반기가 지원 허브 없이, 4선 기가라이트를 지원하는 공유기만 연결한 구성

LuCI의 `UB` / `DS` 카운터는 부팅 이후 수신한 유효 요청 수를 나타냅니다. 카운터는 데몬을 재시작해도 유지되며, 공유기를 재부팅하면 초기화됩니다.

## 기술 설명

통신사에서 반기가라고 부르는 회선에는 두 가지 방식이 있습니다. 하나는 이더넷 8선을 모두 사용해 1Gbps로 링크를 구성한 뒤 인터넷 속도를 500Mbps로 제한하는 방식이고, 다른 하나는 4선 구간에서 전용 장비를 사용해 500Mbps를 제공하는 방식입니다. 이 패키지는 후자인 LGU+ 기가라이트 환경을 대상으로 합니다. 이 기술은 통신3사에서 모두 사용하나, 인증이 필요한 것은 LGU+ 뿐인 것으로 보입니다. 

흔히 “증폭기”라고 부르는 장비나 하프기가 지원 허브에는 4선 구간에서 500Mbps로 통신하기 위한 전용 하드웨어가 들어 있습니다. 따라서 일반 기가비트 공유기 앞에는 반기가 지원 허브가 필요합니다.

LGU+ 환경에서는 지원 허브를 연결하더라도 속도가 100Mbps에 머물거나, 처음에는 500Mbps가 나오다가 이후 100Mbps로 떨어지는 경우가 있습니다. 이 패키지는 통신사 공유기가 처리하던 OAM 요청에 응답해 해당 인증 동작을 재현합니다.
